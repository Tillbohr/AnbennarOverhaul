# Orc Portraits Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `black_orc` characters in a new game have Elder Kings 2's standard orc face, tusks, horns and hair, in brown, gray or black skin.

**Architecture:** Three ethnicities on one `orc_base` deliver five new inherited morph genes, as EK2 does. Tusked teeth come from a portrait modifier on the race traits. EK2's art is imported once and committed under `aov_` names. Head assets move to a shared generator, and hair templates join `build_portraits.py`.

**Tech Stack:** CK3 1.19 script, Python 3 generators and `unittest` under `tools/`, ck3-tiger.

**Spec:** `docs/superpowers/specs/2026-11-05-orc-portraits-design.md`

## Global Constraints

- Work on branch `orc-portraits`. Never write to `../anbennar-ck3-dev-master`, the game or the Workshop folders.
- Script and localization files: UTF-8 with BOM, LF line endings, tabs for indentation.
- Run Python with `-I`. Tests: `python -I tools/run_tests.py <name>`; validation: `python -I tools/validate.py`.
- No clothes, armour or headgear changes. `black_orc` keeps `western_clothing_gfx`. `cave_goblin` keeps `100 = arab`.
- `.mesh` and `.dds` go through Git LFS by the existing `.gitattributes` rules: check `git lfs status` shows them as LFS before committing.
- Generated files are never edited by hand. Rerun the generator.
- Colours, verbatim from the spec (`skin_color` box / `skin_color_saturation` value): `orc_brown` 0.4 0.65 0.8 0.85 / 0.5; `orc_gray` 0.0 0.5 0.2 0.75 / 0.0 to 0.05; `orc_black` 0.0 0.85 0.2 1.0 / 0.0 to 0.05.

## Review Focus

- A non-orc character: their teeth, head and hair must not change. Pinned by Task 2 (the teeth gene file is the game's bytes plus marked lines) and Task 3 (every new gene's index 0 template is empty).
- An orc woman or girl: no horn shape, and no attribute she lacks. Pinned by Task 3 (`test_horns_are_male_only`).
- An orc Lich: no tusks through the skeleton. Pinned by Task 5 (`test_teeth_skip_liches`). The Lich's priority 100 groups already beat the hair and beard groups.
- An orc baby or boy: baby hair and no beard. Pinned by Task 5 (`test_age_conditions`).
- A later Anbennar or game update: a missing anchor, accessory or `teeth_accessory` block must stop the build, not ship a broken file. Pinned by Tasks 1, 2 and 4.
