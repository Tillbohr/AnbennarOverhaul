# Serpentreach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** EU4's Serpentreach as ~124 carved provinces in the CK3 Serpentspine block under a placeholder `e_serpentreach`.

**Architecture:** `tools/serpentreach_layout.py` (pure, deterministic) traces EU4 provinces onto CK3 province 2426
and returns the new province map; `tools/build_serpentreach.py` writes the province map and every script file from
it; `tools/build_map_graphics.py` calls the same layout to carve the heightmap and paint the blend maps.

**Tech Stack:** Python 3 standard library only (`pngio`, `eu4_import`, `pdx_script`, `terrain_fill`), unittest.

**Spec:** `docs/superpowers/specs/2026-11-02-serpentreach-design.md`

## Global Constraints

- Never write to `../anbennar-ck3-dev-master`; new files `aov_`-prefixed; script/loc files UTF-8 BOM + LF, tabs.
- Generated files carry the `# Anbennar Overhaul: generated by tools/build_serpentreach.py` header (text files).
- Output is byte-identical across runs (no randomness without a fixed seed, sorted iteration).
- Python is run with `-I`; tools add their own folder to `sys.path`.
- Only province-2426 pixels may change in `provinces.png`; new ids start at Anbennar's max id + 1 (6944 today).
- Commit only files this plan touches (the working tree holds the user's unrelated uncommitted changes).

## Review Focus

- Anbennar update shifts province 2426 or the neighbours: the fit and clip must still succeed or stop with a named
  error, never write a partial map. Test: `test_layout_rejects_non_2426_change`.
- A county squeezed to too few pixels by clipping: build stops naming the county. Test: `test_split_too_small_raises`.
- New title keys colliding with Anbennar keys: build stops. Test: `test_title_collision_raises`.
- Carving lowering mountain outside the floor or leaving a floor pixel non-flat. Test: `test_carve_profile`.
- Locator override dropping Anbennar instances. Test: `test_locators_keep_existing_instances`.

### Task 1: Layout geometry (`tools/serpentreach_layout.py`, `tools/data/serpentreach.py`)

**Files:** Create `tools/serpentreach_layout.py`, `tools/data/serpentreach.py`; Test `tools/tests/test_serpentreach.py`.

**Interfaces — Produces:**
- `fit_affine(pairs: list[tuple[float,float,float,float]]) -> tuple[tuple[float,float,float], tuple[float,float,float]]`
  (ex, ey, cx, cy pairs -> x and y rows of the affine).
- `slug(name: str) -> str` (`"Argrod | 3 |"` -> `"argrod_3"`, `"Gor Búrad"` -> `"gor_burad"`, `"Arg-Ördstun"` -> `"arg_ordstun"`).
- `display_name(name: str) -> str` (`"Argrod | 3 |"` -> `"Argrod 3"`).
- `split(pixels: list[tuple[int,int]], k: int, min_px: int, label: str) -> list[list[tuple[int,int]]]` (k-means,
  capital piece first; raises `GeneratorError` naming `label` when `len(pixels) < k * min_px`).
- `chamfer(mask: set[tuple[int,int]], box, limit: int) -> dict[(x,y), int]` distances (8-neighbour, 1 per step).
- `Layout` namedtuple: `width, height, base_ids (dict colour->id, as loaded), counties (list of County),
  provinces (dict new id -> Province), pixel_owner (dict (x,y)->new id), openings (list)`;
  `County(key, eu4_id, name, area, type, baronies: list[int])`, `Province(id, colour, county, index, pixels, interior)`.
- `layout(anbennar: Path, eu4: Path) -> Layout`.
- Data constants (spec values): `WALL_MARGIN=4`, `OPENING_WIDTH=6`, `MIN_BARONY_PX=60`, `BARONIES={"dwarven_hold":4,
  "dwarven_hold_surface":4,"cavern":2,"dwarven_road":1}`, `BARONY_OVERRIDES={}`, `OPENING_TARGETS={}`,
  `SOURCE_PROVINCE=2426`, `REGION="serpentreach_region"`, `FIT_BOX=(2950,480,3550,760)`, `KINGDOMS` (3 lists of the
  19 EU4 area keys, west/centre/east by area centroid x), `CULTURE="stone_dwarvish"`, `RELIGION="ancestor_worship"`,
  `BARONY_SUFFIXES=("Halls","Deeps","Vaults")`, terrace/wall constants for Task 3.

- [ ] Step 1: tests `test_fit_affine_recovers_transform` (synthetic points through x'=3.5x+1, y'=3.6y-2 recovered to
  1e-6), `test_slug_and_display_name` (the three examples above), `test_split_deterministic_and_connected`
  (40x10 rectangle, k=4: same output twice, every piece 4-connected, sizes sum to 400),
  `test_split_too_small_raises`, `test_chamfer` (single pixel: neighbours 1, distance-2 ring 2).
- [ ] Step 2: run `python -I -m unittest discover -s tools/tests -p "test_serpentreach*.py"`; expect import failure.
- [ ] Step 3: implement. `layout`: load CK3 map + definition (pngio), EU4 bmp + definition + areas + names + terrain
  overrides (eu4_import); fit on matched centroids in `FIT_BOX`; for the transformed region box, inverse-map each
  2426 pixel; keep pixels with chamfer distance to non-2426 >= `WALL_MARGIN`; per county split; openings from EU4
  entrances (EU4 4-neighbour pairs serp/non-serp land, wasteland excluded) to the target province, corridor pixels on
  2426 only, assigned to the capital barony; assign ids and colours (golden-ratio hue walk, skip used colours);
  interior = floor pixel of max chamfer distance to the barony edge (ties: smallest (y,x)).
- [ ] Step 4: tests pass.
- [ ] Step 5: commit.
