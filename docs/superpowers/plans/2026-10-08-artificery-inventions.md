# Artificery Inventions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fill the Artificery window's Inventions tab with 60 EU4-derived inventions: faction-sponsored research, era-gated tiers, Economic/Military/Society filters, 3/4/5 activation slots with a 1-year cooldown, heir inheritance, AI use and three new men-at-arms.

**Architecture:** A data table (`tools/data/inventions.py`) feeds a generator (`tools/build_inventions.py`) that writes every file repeating one block per invention (modifiers, triggers, values, effects, scripted GUIs, list GUI, loc, custom loc, icons). Hand-written files hold the research timer, slots, inheritance, AI, events, the research popup and the Inventions tab layout. State lives in character variables on the ruler.

**Tech Stack:** CK3 1.19.0.6 script and PdxGui; Python 3 stdlib (`unittest`); ck3-tiger via `tools/validate.py`.

**Spec:** `docs/superpowers/specs/2026-10-08-artificery-inventions-design.md` (content: `docs/research/2026-10-08-eu4-artificer-inventions.md`; shell: `docs/superpowers/specs/2026-10-08-artificery-tab-shell-design.md`)

## Global Constraints

- Never write to `../anbennar-ck3-dev-master`, the game install, or the EU4 Workshop folder; read only.
- Script, GUI, localization files: UTF-8 **with BOM**, **LF**, tabs. Python: UTF-8 no BOM, LF, 4 spaces. Run Python with `python -I`.
- New files use the `aov_` prefix. Generated files start with `# Anbennar Overhaul: generated by tools/build_inventions.py ...; do not edit by hand.`
- Era per tier: 1 `culture_era_early_medieval`, 2 `culture_era_high_medieval`, 3 `culture_era_late_medieval`.
- Research: Brillites 20 quarters (5 y), Mechanists 40 (10 y), Technomancers 60 (15 y); cost 50 gold for every sponsor.
- Slots: 3 / 4 / 5 by the ruler's culture era (high medieval → 4, late medieval → 5); 1-year cooldown per emptied slot, at most 5 cooldowns.
- State variable names exactly as in the spec's State table (`aov_inv_<key>`, `aov_inv_<key>_order`, `aov_inv_activation_counter`, `aov_research_sponsor`, `aov_research_category`, `aov_research_target`, `aov_research_quarters_left`, `aov_tech_offer_<category>_<1-3>`, `aov_slot_cd_<1-5>`, `aov_artificery_dormant`) plus `aov_last_discovered`, `aov_last_sponsor`, `aov_tech_offers_rolled_<category>`.
- GUI never reads script variables directly (vanilla has no `Var().IsSet`); every state check goes through a scripted GUI or a script value.
- Work on branch `artificery-tab`; commit per task; stage only the task's files (the user has an unrelated `CLAUDE.md` hunk: stage this plan's CLAUDE.md hunks only).

## Review Focus

1. **Research completion when the pool emptied** (faith change, everything discovered): must refund 50 gold and fire the refund event, never discover nothing silently. Test: `test_complete_research_refunds_when_nothing_discovered` (Task 4, static check of the effect) + in-game step (Task 7).
2. **Over-maximum slots after inheritance / culture change:** must deactivate newest first and terminate. Test: `test_deactivate_newest_is_a_single_chain` (Task 2) + in-game step (Task 7).
3. **Dormant ruler** (lost academy, non-gnome heir): no modifiers, no research progress, everything restored once eligible. Test: `test_suspend_and_resume_cover_every_invention` (Task 2) + in-game step (Task 7).
4. **Technomancer offer re-rolling** by reopening the popup or reselecting a category must not change offers within a cycle. Test: `test_technomancer_category_sgui_rolls_only_once` (Task 4).
5. **Filter + status combinations** (filtered category, locked tier, faith-hidden invention) must hide or grey rows correctly. Test: `test_row_visibility_uses_visible_sgui_and_category_filter` (Task 3) + in-game step (Task 7).

## Deviations from the spec (decided while planning)

- **No `on_culture_era_changed` hook:** a new era only raises the slot maximum, and the quarterly pulse already
  enforces the maximum after inheritance or culture change.
- **On_action file is `aov_inventions_on_actions.txt`** (spec: `aov_artificery_on_actions.txt`), to avoid confusion
  with the existing `aov_artificer_on_actions.txt`.
- **Inherited cooldowns restart at a full year:** CK3 cannot read how long a timed variable has left.
- **Generated script values file** `common/script_values/aov_invention_values.txt` (active count, newest order) in
  addition to the spec's generated list; hand-written values are in `aov_artificery_values.txt`.
- **Status display through scripted GUIs** (7 per invention): vanilla GUI has no `Var().IsSet`.
- **Research panel shows the sponsor by name only** (no sponsor icon: there is no faction art yet).
- **Two research-doc keys replaced** with verified ones: Artillery Autoloader uses `siege_phase_time` +
  `siege_weapon_max_size_add`; Runethought Network uses `cultural_acceptance_gain_mult` +
  `cultural_head_fascination_mult`. Prototype Tanks, War Golems and the Megacannon keep a small modifier besides
  their MaA unlock so activating them always has an effect.
- **Popup flow:** each sponsor/category/offer button starts research directly (no separate Confirm button).
- **`travel_speed` is additive** in CK3 (vanilla uses 5-20), so those values are whole numbers.

class GeneratorError(Exception):

def load_inventions(path: Path = DATA) -> list:
    spec = importlib.util.spec_from_file_location("aov_inventions_data", path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module.INVENTIONS


def validate(invs: list) -> None:
    keys = [i["key"] for i in invs]
    if len(set(keys)) != len(keys):
        raise GeneratorError("duplicate invention keys")
    for i in invs:
        k = i["key"]
        if not re.fullmatch(r"[a-z0-9_]+", k):
            raise GeneratorError(f"{k}: bad key")
        if i["category"] not in CATEGORIES:
            raise GeneratorError(f"{k}: bad category {i['category']}")
        if i["tier"] not in ERAS:
            raise GeneratorError(f"{k}: bad tier {i['tier']}")
        if i["faith"] is not None and i["faith"] not in FAITHS:
            raise GeneratorError(f"{k}: faith trigger not in allow-list: {i['faith']}")
        if i["maa"] is not None and i["maa"] not in MAA_KEYS:
            raise GeneratorError(f"{k}: unknown MaA {i['maa']}")
        if not re.fullmatch(r"Artf_\w+\.dds", i["icon"]):
            raise GeneratorError(f"{k}: bad icon {i['icon']}")
        if not i["modifier"].strip() or not i["name"] or not i["desc"]:
            raise GeneratorError(f"{k}: empty modifier, name or desc")
        if '"' in i["name"] + i["desc"]:
            raise GeneratorError(f"{k}: double quote in name or desc")


def of(invs, category=None, tier=None):
    return [i for i in invs if (category is None or i["category"] == category) and (tier is None or i["tier"] == tier)]


def any_of(name: str, comment: str, invs: list, cond) -> str:
    lines = "\n".join(f"\t\t{cond(i)}" for i in invs)
    return f"# {comment}\n{name} = {{\n\tOR = {{\n{lines}\n\t}}\n}}\n"


def chain(invs: list, limit, effect) -> str:
    parts = []
    for n, i in enumerate(invs):
        kw = "if" if n == 0 else "else_if"
        parts.append(f"\t{kw} = {{\n\t\tlimit = {{ {limit(i)} }}\n\t\t{effect(i)}\n\t}}")
    return "\n".join(parts)


def draw(invs: list, cond, effect, depth: int = 1) -> str:
    t = "\t" * depth
    opts = "\n".join(f"{t}\t1 = {{\n{t}\t\ttrigger = {{ {cond(i)} }}\n{t}\t\t{effect(i)}\n{t}\t}}" for i in invs)
    return f"{t}random_list = {{\n{opts}\n{t}}}"


def offered(i) -> str:

    return " ".join(
        f"AND = {{ has_variable = aov_tech_offer_{c}_{n} var:aov_tech_offer_{c}_{n} = flag:{k} }}" for n in range(1, OFFERS + 1)

def gui(invs: list) -> str:
    parts = [HEADER, "types AovInventions\n{\n", "\ttype aov_inventions_list = vbox {\n\t\tspacing = 2\n\n"]
    for t in (1, 2, 3):
        parts.append(
            f"\t\ttext_single = {{\n\t\t\tlayoutpolicy_horizontal = expanding\n\t\t\tmargin_top = 8\n"
            f"\t\t\ttext = \"AOV_INVENTIONS_TIER_{t}\"\n\t\t\tdefault_format = \"#T\"\n\t\t\talign = left|nobaseline\n\t\t}}\n\n"
        )
        parts.extend(row(i) + "\n" for i in of(invs, tier=t))
    parts.append("\t}\n\n")
    for c in CATEGORIES:
        parts.append(f"\ttype aov_inventions_offers_{c} = vbox {{\n\t\tspacing = 4\n\n")
        parts.extend(offer_row(i) + "\n" for i in of(invs, c))
        parts.append("\t}\n\n")
    parts.append("}\n")
    return "".join(parts)

        "common/scripted_guis/aov_invention_sgui.txt": sguis(invs),
        "common/customizable_localization/aov_invention_custom_loc.txt": custom_loc(invs),
        "gui/aov_inventions_generated.gui": gui(invs),
        "localization/english/aov_inventions_l_english.yml": loc(invs),
    }


def write_all(files: dict, root: Path) -> None:
    for rel, text in files.items():
        out = root / rel
        out.parent.mkdir(parents=True, exist_ok=True)
        out.write_bytes(b"\xef\xbb\xbf" + text.replace("\r\n", "\n").encode("utf-8"))


def copy_icons(invs: list, eu4: Path, root: Path) -> None:
    src_dir = eu4 / EU4_ICONS
    names = sorted({i["icon"] for i in invs})
    missing = [n for n in names if not (src_dir / n).is_file()]
    if missing:
        raise GeneratorError(f"EU4 icons not found in {src_dir}: {', '.join(missing)}")
    dst = root / ICON_DIR
    dst.mkdir(parents=True, exist_ok=True)
    for n in names:
        shutil.copyfile(src_dir / n, dst / n)


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--eu4", type=Path, default=DEFAULT_EU4)
    args = parser.parse_args()
    try:
        invs = load_inventions()
        validate(invs)
        files = render_all(invs)
        write_all(files, SUBMOD)
        copy_icons(invs, args.eu4, SUBMOD)
    except GeneratorError as e:
        sys.exit(f"error: {e}")
    print(f"wrote {len(files)} files and {len({i['icon'] for i in invs})} icons for {len(invs)} inventions")


if __name__ == "__main__":
    main()
