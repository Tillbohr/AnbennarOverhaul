# Magic Advancements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each magic school one three-level advancement (EU4 Anbennar's magical projects) and split the Magic window into Advancements and Spells tabs.

**Architecture:** `tools/data/advancements.py` + `tools/build_advancements.py` generate the repetitive per-advancement script (start/abandon buttons, triggers, cost values, progress tick, completion dispatch, GUI pages, loc), like `build_spells.py`. Each level's effect is a hand-written `aov_adv_<key>_<n>_effect`, with its own content files (buildings, MaA, traits, events). The study/advancement exclusivity is enforced by the generated start effect (clears study) and the study scripted GUIs (generated by `build_spells.py`).

**Tech Stack:** CK3 1.19 script and PdxGui; Python 3 standard library (`unittest`); ck3-tiger via `tools/validate.py`.

**Spec:** `docs/superpowers/specs/2026-10-22-magic-advancements-design.md`

## Global Constraints

- Script and loc files: UTF-8 with BOM, LF line endings, tabs (the generator writes BOM + LF like `build_spells.write_all`).
- New files use the `aov_` prefix; keys are not prefixed except where this plan names them (`aov_adv_*`, `aov_homunculus`).
- Never edit `../anbennar-ck3-dev-master`. Never hand-edit a generated file; change `tools/data/advancements.py` or the generator and rerun.
- Eligibility everywhere: `is_landed = yes` and `aov_is_mage = yes` (trigger `aov_adv_eligible`).
- Placeholder costs per level 1/2/3: gold 100 / 200 / 400, mana 50 / 75 / 100, duration 2 / 3 / 4 years.
- Level N of an advancement needs `aov_school_level_at_least = { SCHOOL = <school> LEVEL = N }`.
- Every effect number other than cost and duration lives in `common/script_values/aov_advancement_tuning.txt` (modifier blocks may hold literals, but each literal also appears in the tuning file comment so balance is edited in one place).
- Before using any modifier or effect name not already used in the mod, grep the game's `common/` for it; if absent, pick a vanilla one.
- Run tests with `python -I -m unittest discover -s tools/tests -p "test_<name>*.py"`; run tiger with `python -I tools/validate.py`.
- Every `change_variable` target must be created in the same file (`test_script_hygiene.py`).

## Review Focus

1. **AI re-study clobbers a commitment:** `aov_magic_ai_quarterly` sets a study school whenever `aov_studying` is unset, which is exactly the state a commitment leaves. Expect a committed AI mage to keep its advancement. Test in Task 3.
2. **Mage stops being eligible mid-commitment** (loses all land, loses affinity): expect the commitment to be abandoned on the next quarterly tick, without completing. Test in Task 3.
3. **Stored artifact no longer exists** (destroyed phylactery or enchanted item): `var:` pointing at a dead artifact must not error; every check uses `exists = var:x` before `var:x = { ... }`. Test in Tasks 8 and 11.
4. **Lich trait cannot be added** (mage already has an opposite of `lich`: `incapable vampire immortal lycanthrope`): expect Lichdom level 3 to be unstartable, not to eat the prisoner and give nothing. Test in Task 11.
5. **Committed to one school's advancement while viewing another school's Advancements tab:** expect that tab's Start button disabled with a tooltip naming the advancement in progress, and the in-progress line visible. Test in Task 4.

Generated behaviour the tests pin:

- `aov_adv_<key>_can_start`: `aov_adv_eligible = yes`; `NOT = { aov_adv_is_committed = yes }` (custom tooltip `AOV_ADV_REQ_NOT_COMMITTED`); `aov_adv_<key>_level < 3`; school level at least `aov_adv_<key>_level + 1` (one `trigger_if` per level 0/1/2, each `aov_school_level_at_least = { SCHOOL = <school> LEVEL = n+1 }`, followed by that level's `requires` triggers); `gold >= aov_adv_<key>_next_gold`; `aov_mana >= aov_adv_<key>_next_mana`.
- `aov_adv_<key>_start`: `remove_short_term_gold = aov_adv_<key>_next_gold`, `aov_mana_spend = { AMOUNT = aov_adv_<key>_next_mana }`, `remove_variable = aov_studying`, sets `aov_adv_committed = flag:<key>`, `aov_adv_working_level = aov_adv_<key>_level + 1`, `aov_adv_progress = 0`.
- `aov_adv_abandon`: removes `aov_adv_committed`, `aov_adv_working_level`, `aov_adv_progress`; no refund.
- `aov_adv_quarterly`: if committed and `aov_adv_eligible = no` → `aov_adv_abandon`; else `change_variable aov_adv_progress add 3`, and when `aov_adv_progress >= aov_adv_months_needed` call `aov_adv_<key>_complete` for the committed key.
- `aov_adv_<key>_complete`: sets `aov_adv_<key>_lvl = var:aov_adv_working_level`, saves `scope:aov_adv = flag:<key>` and `scope:aov_adv_level`, calls `aov_adv_<key>_<n>_effect` for the working level, `trigger_event = aov_advancement.1`, then `aov_adv_abandon` (clears state).
- `aov_adv_months_needed` = `YEARS[level-1] * 12` for `var:aov_adv_working_level`.
- GUI page per school: school level badge (same `levels_strip.dds` icons as the spell page), `aov_adv_<key>` title, three level icons with tooltips `aov_adv_<key>_<n>_desc` (done/next/locked frames via `aov_adv_<key>_level`), cost text `AOV_ADV_COST` (gold and mana from `_next_gold`/`_next_mana`), Start `button_standard` bound to `aov_adv_<key>_start_sgui` (`enabled` = IsValid, `tooltip` = BuildTooltip), and while `aov_adv_working_on = { KEY = <key> }` a `progressbar_standard` (`aov_adv_progress_percent`) and Abandon button bound to `aov_adv_abandon_sgui`. A line `AOV_ADV_IN_PROGRESS_ELSEWHERE` shows when committed to another key, and `AOV_ADV_ENDS_STUDY` ("Starting ends your study of [school]", via the existing `aov_studying` custom loc) shows next to Start while the mage is studying.
