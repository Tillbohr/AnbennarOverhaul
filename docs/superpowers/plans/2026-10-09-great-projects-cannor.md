# Great Projects (Cannor) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The 82 EU4 great projects in Cannor become CK3 special buildings (64 new chains, 14 extended Anbennar chains, 3 placeholder chains, 1 canal excluded), placed in their baronies, with translated EU4 effects and their EU4 painting as county-view holding art.

**Architecture:** A shared EU4 reader (`tools/eu4_monuments.py`) feeds an importer that writes curated data (`tools/data/monuments/cannor.py`, plus hand fixes in `cannor_hand.py`) through one translation table. A generator (`tools/build_monuments.py`) turns the data into buildings, overrides of Anbennar's chains (copied from Anbennar's current file), history, loc, art, custom loc and a county-view GUI override.

**Tech Stack:** CK3 1.19.0.6 script, PdxGui, ck3-tiger (`python -I tools/validate.py`), Python `unittest` in `tools/tests/`, pure-Python DDS (no Pillow).

**Spec:** `docs/superpowers/specs/2026-10-09-great-projects-cannor-design.md`

## Global Constraints

- Base Anbennar (`../anbennar-ck3-dev-master`) is never edited. Script/loc/gui: UTF-8 BOM + LF + tabs; Python/Markdown: no BOM, LF, `write_bytes`.
- EU4 roots (app 236850 Workshop): Anbennar `1385440355`, Cannorian Monuments `2811184350`, Dwarven Monuments `2791499822`. Precedence for a key defined twice: Cannorian, then Dwarven, then Anbennar.
- Cannor = EU4 superregions `western_cannor_superregion`, `escann_superregion`, `gerudia_superregion` (82 projects).
- Excluded: type `canal` (Marrhold Tunnel). No other exclusions.
- New keys `aov_monument_<eu4key>_01/_02/_03`. Castle Dameris chain: `castle_dameris_01/_02/_03`, all named "Castle Dameris" (EU4 `imperial_palace_anbenncost`); `imperial_palace_anbennar_*` unused.
- Start level 1 iff EU4 `starting_tier >= 1` and EU4 `date` year < 1022; else empty slot. Anbennar-placed chains keep Anbennar's history.
- Cost: EU4 `cost_to_upgrade.factor` × 0.4 gold (1000/2500/5000 → 400/1000/2000). Time: EU4 `upgrade_time.months` × 0.5 → `construction_time` in days (months × 15).
- EU4 block → CK3 block: `province_modifiers` → `province_modifier` or `county_modifier` (per translation row), `area_modifier` → `duchy_capital_county_modifier`, `country_modifiers` → `character_modifier`.
- Kobold projects without a same-named title (`kobildzan_kobildzex_guild_of_trapsmiths`, `the_dragonhoard`) → county `c_soxun_kobildzex`.
- Generated files carry `# Anbennar Overhaul: generated by tools/build_monuments.py ...; do not edit by hand.`

## Review Focus

1. Two monuments in one county with too few free baronies (an Anbennar slot already taken): the importer must report it, never place two slots in one barony. *(Task 3 test `test_shared_county_without_free_barony_is_reported`.)*
2. An Anbennar update renames or removes a chain key this mod overrides: the generator must stop with an error, not emit a stray definition. *(Task 6 test `test_missing_anbennar_key_errors`.)*
3. A project redefined by a submod with different tiers: the submod's version is used. *(Task 1 test `test_submod_precedence`.)*
4. Names with accents/apostrophes ("Lorentainé", "Humac's Rest", "Blaíddscal"): matched to CK3 titles. *(Task 3 test `test_name_matching_ignores_accents_and_punctuation`.)*
5. A tier whose EU4 modifiers are all dropped: the level is still a valid building with no empty modifier block. *(Task 5 test `test_level_without_modifiers_has_no_empty_blocks`.)*
